Blueprint Manager

Your blueprints, tidy: back up, delete, put back, and send downloads straight into your game.

This browser can’t open folders for a web page. The Blueprint Manager works in Chrome and Edge on a PC. Firefox and Safari don’t offer folder access — you can still download blueprints from the library and move them in by hand, or use the one-click importer.

What you allow

Nothing happens until you tick a box and press the button. Everything runs here in your browser — your files are never uploaded. Chrome / Edge will also ask you once more in their own words, and you can take it back any time.

  • You pick the folder (your Transport Fever 2 folder, where blueprint_*.lua files live). The page sees only that folder.
  • It reads the first lines of each blueprint file (name, date, version) to list them, and checks whether the mod’s 10 import slots (blueprint_import*.lua) are empty so a download never overwrites one that’s waiting.
  • It only writes or deletes blueprint_*.lua files when you press a button that names them first. Anything deleted is copied to a BPX backups folder first.
  • It never opens the mod’s own files (index, settings, log) or anything else in that folder.
  • The page saves a random key in bpx_player_key.txt in that folder. Opening the folder signs you in — no name, email, password or Steam account.
  • tfbpx.com stores a scrambled copy of the key and the list of blueprints you download here (which one, when, how many times). That’s all.
  • Forget me deletes all of it from the site, straight away.
  • You pick your Steam Workshop and/or mod.io mods folder. The page reads only the folder names — they’re the mod numbers.
  • The list stays in this browser and is never sent to us. The library then shows which blueprints you can place with the mods you have.
Read the code
Chrome says “Can’t open this folder because it contains system files”

Browsers won’t let any web page into C:\Program Files or C:\Program Files (x86), and that’s where Steam puts Transport Fever 2 unless you chose another drive. If your game lives on another drive (like D:\SteamLibrary\...) it works today.

The next Blueprint Exchange update keeps your blueprints in Documents\Blueprint Exchange, which every browser can open. Until then, download from the library as usual or use the one-click importer.
