Share a blueprint

Pick the file the mod saved next to your game (blueprint_<name>.lua). It's checked here before upload — only real Blueprint Exchange files, plain data, no code.

Where the files are: the game's install folder, the one with TransportFever2.exe. Usually C:\Program Files (x86)\Steam\steamapps\common\Transport Fever 2 — or, if the game lives on another drive, <drive>:\SteamLibrary\steamapps\common\Transport Fever 2. Quickest way there: Steam → right-click Transport Fever 2 → Manage → Browse local files.

Uploads are public and permanent.

How to use a downloaded blueprint

  1. Put the downloaded blueprint_import.lua file next to the game's executable — usually C:\Program Files (x86)\Steam\steamapps\common\Transport Fever 2 (or <drive>:\SteamLibrary\steamapps\common\Transport Fever 2 on another drive). In Steam: right-click Transport Fever 2 → Manage → Browse local files opens it for you.
  2. In game, click BP in the bottom bar, then [ Import ] — the mod reads the inbox file and files the blueprint into your library under its own name. One download at a time: import before downloading the next.
  3. Click [ Place ], aim the blue outline at flat, clear ground, rotate if you like, and left-click. If it needs mods you don't have, the status line names them.

Inspired by Copy It! by okeating — a superb TF2 utility whose approach to capturing and rebuilding constructions and track is the foundation Blueprint Exchange builds on.
