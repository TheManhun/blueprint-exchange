Downloaded one? The mod won't see it until you do this

The game can't look inside its own folder, so a download only shows up after you move it there and press one button.

  1. Grab as many as you like — each download from this page gets its own file (blueprint_import.lua, blueprint_import_2.lua, and so on). Find them in your Downloads folder.
  2. Move them all into the Transport Fever 2 game folder — the one with TransportFever2.exe. Not sure where that is? The picture below shows the three Steam clicks.
  3. In game, click BP in the bottom bar, then Import downloads. One press picks up everything you moved in and files each blueprint into your library under its own name.
  4. Press Place, aim the blue outline at flat, clear ground, turn it if you like, and left-click. If it needs a mod you don't have, the status line names it.

Up to 10 downloads can wait at once (see the counter above the list) — the site blocks the 11th until you say you've moved the files in.

Built something good? Add it to the library

For designers: capture your layout in game, then upload the file it made.

  1. In game, open BP → Capture a design and follow the numbered steps. Full walkthrough with pictures in the guide.
  2. The mod saves it as blueprint_<name>.lua in the same game folder shown above.
  3. Pick that file here, add a line about it, upload. Re-uploading the same blueprint later becomes v2, v3… automatically.

Files are checked before upload — only real Blueprint Exchange files, plain data, no code.
