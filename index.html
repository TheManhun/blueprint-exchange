Blueprint Exchange is a fan-made community project for Transport Fever 2 players. It is unofficial and not affiliated with, endorsed by, or the responsibility of the game’s developers or publishers.

Inspired by Copy It! by okeating — a superb TF2 utility whose approach to capturing and rebuilding constructions and track is the foundation Blueprint Exchange builds on.

Blueprint Exchange is free — support is completely optional.

Downloaded

  1. Move into your game folder — usually C:\Program Files (x86)\Steam\steamapps\common\Transport Fever 2 (Steam → right-click Transport Fever 2 → Manage → Browse local files opens it). Downloading more? Each one gets its own file name, so grab a few before moving them in. Or make a one-click importer that does the moving for you.
  2. In game: BPX → Import downloads. It lands in your library as — one press picks up everything you moved in, not just this one.
  3. Place, aim, click. Need more help? See the download and import guide.
