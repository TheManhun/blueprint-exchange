Downloaded one? The mod won't see it until you do this

The game can't look inside its own folder, so a download only shows up after you move it there and press one button.

  1. Every download from this page is named blueprint_import.lua. Find it in your Downloads folder.
  2. Move it into the Transport Fever 2 game folder — the one with TransportFever2.exe. Not sure where that is? The picture below shows the three Steam clicks.
  3. In game, click BP in the bottom bar, then Import a download. The blueprint joins your library under its own name.
  4. Press Place, aim the blue outline at flat, clear ground, turn it if you like, and left-click. If it needs a mod you don't have, the status line names it.

One download at a time: import it before downloading the next, or the second overwrites the first.

Built something good? Add it to the library

For designers: capture your layout in game, then upload the file it made.

  1. In game, open BP → Capture a design and follow the numbered steps. Full walkthrough with pictures in the guide.
  2. The mod saves it as blueprint_<name>.lua in the same game folder shown above.
  3. Pick that file here, add a line about it, upload. Re-uploading the same blueprint later becomes v2, v3… automatically.

Files are checked before upload — only real Blueprint Exchange files, plain data, no code.

Uploads are public and permanent.

Inspired by Copy It! by okeating — a superb TF2 utility whose approach to capturing and rebuilding constructions and track is the foundation Blueprint Exchange builds on.

Downloaded

  1. Move into your game folder — usually C:\Program Files (x86)\Steam\steamapps\common\Transport Fever 2 (Steam → right-click Transport Fever 2 → Manage → Browse local files opens it).
  2. In game: BP → [ Import ]. It lands in your library as .
  3. [ Place ], aim, click. (Import each download before grabbing the next — the inbox holds one file.)
