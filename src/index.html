Downloaded

  1. Move into your game folder — usually C:\Program Files (x86)\Steam\steamapps\common\Transport Fever 2 (Steam → right-click Transport Fever 2 → Manage → Browse local files opens it).   2. In game: BPX → Import downloads. It lands in your library as — one press picks up everything you moved in, not just this one.
  3. Place, aim, click. Need more help? See the download and import guide.
