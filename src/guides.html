Download & Import Blueprints

The game can’t look inside its own folder, so a download only shows up after you move it there and press one button.

  1. Download as many blueprints as you like from the library, up to 10 at a time.
  2. The files land in your Downloads folder named blueprint_import.lua, blueprint_import_2.lua, blueprint_import_3.lua and so on — each download gets the next name.
  3. Move them into the Transport Fever 2 folder (the one with TransportFever2.exe), or let a Blueprint Importer do the moving for you.
  4. Start Transport Fever 2.
  5. Click the BPX icon in the bottom bar.
  6. Press Import downloads. One press brings in every blueprint you moved. Then choose one in the Library and press Place.

Capture Your Own Blueprint

Build it once, capture it, and place it on any map — yours or someone else’s.

  1. Build your layout in a sandbox game. Flat ground is best — use the terrain tool to level a patch first, and your blueprint will place cleanly anywhere. (The map editor has no rails, so build in a game.)
  2. Click the BPX icon in the bottom bar and press Capture.
  3. Type a name and press Confirm name.
  4. Click on the map to sweep circles over your layout. Every click adds a circle and the strip counts what it found. Remove takes pieces back out, and the slider makes the circle bigger or smaller.
  5. Press Save. A test copy of your blueprint appears on the cursor: turn it with the slider or the -90° and +90° buttons and click the map to build it.
  6. Look it over. Happy with it? Press Ready to save. It goes into your Library and the test copy is removed. Missed a bit? Cancel and capture again with a wider sweep.

As it saves, BPX tidies up small hand-drawn slips: a road drawn at 91° is squared to 90°, and small kinks in a slope are smoothed. Anything attached to a building stays exactly where you put it. The Log tab lists what it changed.

Placed it in the wrong spot?

Press Undo at the top of the BPX window. It removes everything the last placement built, and it also takes back the last Move or Delete.

Where is the file? Your blueprint is saved as blueprint_<name>.lua in the Transport Fever 2 folder, right next to TransportFever2.exe. That is the file you upload.

If the game refuses a spot, the status line says why in the game’s own words (“Collision”, “Too much slope”) and nothing is built. Try flatter, clearer ground, or turn the layout — a long one needs room along its whole length.

What gets captured

Player-built constructions (stations, depots, assets) with their names, free-laid track and roads with their switches, bridges and tunnels, and signals. Capture leaves industries and town buildings out. To bring an industry along, use Copy or Move with Industries switched on, or place one of the 16 base-game industries from the built-in Library.

Upload & Share

  1. Go to Upload My Blueprint.
  2. Choose your blueprint_<name>.lua file. It is checked in your browser first: only real Blueprint Exchange files, plain data, no code.
  3. Add a screenshot if you like. Paste one with Ctrl+V or choose an image, then drag and zoom to frame it. It is cropped and shrunk in your browser before it is uploaded.
  4. Check the title and description. A live preview shows exactly how your card will look.
  5. Press Upload Blueprint. Uploads are public.

Captured the same design again and want to publish an improved version? Upload the new file and it becomes v2, v3 and so on, with only the latest version shown.

Editing your upload later — no account needed

Keep your original blueprint .lua file safe.

It is your ownership/recovery key for editing this upload later.

Your public downloadable blueprint does not contain the private edit key.

  • After you upload, this browser remembers that you own the blueprint. On the library page your cards show an Edit button, and you can change the title, description and screenshot.
  • New computer, new browser, or cleared your browser data? On the Upload page use I own this blueprint and choose your original .lua files (as many as you like). Each is checked automatically and edit access comes straight back.
  • A file downloaded from the library can’t be used for this — it doesn’t contain the private key.
  • “Remove this browser’s access” (under My blueprints) only forgets the permission on that browser. It never deletes your blueprint.

Find Your Transport Fever 2 Folder

  1. Open Steam and find Transport Fever 2 in your Library.
  2. Right-click it, choose Manage, then Browse local files. (The Properties → Installed Files → Browse button gets you to the same place.)
  3. A folder opens. That is your Transport Fever 2 folder — you will see TransportFever2.exe in it.

The usual path is:

C:\Program Files (x86)\Steam\steamapps\common\Transport Fever 2

If your Steam library is on another drive, it looks more like D:\SteamLibrary\steamapps\common\Transport Fever 2. Use “Browse local files” and you never have to guess.

Dependencies

A dependency is something a blueprint needs that isn’t part of the base game — for example a station or signal that comes from a Workshop mod. If your layout uses mod content, its blueprint depends on that mod.

  • Every blueprint records the content it uses: constructions, track and road types, bridges, tunnels and signal models.
  • BPX knows which of those come with the base game. Anything else is external mod content. A blueprint captured with the current mod records which Steam Workshop or mod.io mod each piece came from, so the upload page just lists the mods it needs and attaches them when you press Upload — nothing to type. Older blueprints without that record ask you for the Workshop ID once.
  • A blueprint can’t be published while it uses external content BPX can’t identify. Cards show “Requires: 1 Workshop mod”, and open to a link to the Workshop page. Blueprints that only use base game content list nothing.
  • When you press Place, BPX checks each item against what is installed before it builds anything. If something is missing you get a message naming it, and nothing is built.

To use a blueprint that needs a mod you don’t have, subscribe to that mod on the Steam Workshop, load your game with it enabled, and try again. BPX never guesses or swaps in a substitute.

Troubleshooting

The Import downloads button sees nothing

The files must be in the Transport Fever 2 folder itself — the one with TransportFever2.exe — not a subfolder and not Downloads. The names must be exact: blueprint_import.lua, blueprint_import_2.lua and so on up to _10.

A name like blueprint_import (1).lua is not recognised — rename it to remove the (1). You don’t need to restart the game: put the files in, then press Import downloads again.

I downloaded more than one blueprint

That’s fine. Each download gets its own numbered name, up to 10 at a time; the counter on the library page tells you how many are waiting. Move them all into the game folder, then press Import downloads once and they all come in together.

At 10 the site pauses further downloads so it can’t overwrite a file you haven’t imported. Move the files in, then press “I’ve moved them — reset downloads”.

Where did my file go?

Downloads go to wherever your browser saves files — usually your Downloads folder. Your browser’s Settings → Downloads shows where.

After a successful import the mod saves the blueprint under its own name as blueprint_<name>.lua in the game folder and empties the import file. A tiny import file afterwards is normal.

Windows saved my .bat as .txt

In Notepad’s Save As box set Save as type to All Files and type the full name Blueprint_Importer.bat. Already saved as .txt? Turn on View → Show → File name extensions in File Explorer and rename it. Or use Download My Blueprint Importer on the Tools page for the file directly.

The blueprint uses a mod I don’t have

BPX refuses to place it, tells you which content is missing, and builds nothing. Install the mod that provides it, enable it in your game, and try again. See Dependencies.

My imported layout looks different

Place it on flat, clear ground. A blueprint captured on almost level ground is flattened so it fits anywhere; one with deliberate slopes, bridges or tunnels keeps its heights, so it needs ground that suits it. If the game refuses a spot it says why and builds nothing.

Not right after placing? Undo last blueprint placement takes back everything that placement built. If a layout doesn’t capture or rebuild correctly, that’s useful to know — BPX is a public beta and unusual layouts are exactly what it needs testing on.
