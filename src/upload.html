Uploading a new version of an existing blueprint?

If the system recognises the same blueprint entry, it can be published as v2, v3 and so on. Every blueprint the mod captures carries a hidden identity, so uploading the file from a later capture of the same design updates its card. The version counter goes up by itself and only the latest version is shown.

New versions are checked against a hidden key inside the file the mod saved on your PC, so only the original uploader can update a blueprint. Keep your own blueprint files safe.
