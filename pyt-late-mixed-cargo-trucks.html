What it does

Grain, fuel, tools and planks — in the same truck, on the same trip. Four later trucks, each with four cargo slots, and every slot takes bulk, liquid, goods or flatbed cargo. One truck, one trip, a mixed load.

▶ Get the whole set in one click: PYT - Mixed Cargo Collection — the Early and Late trucks, the Vanilla Conversion Kit (59 base-game vehicles) and Load Planner.

Version 1.2

The game's trucks carry one kind of cargo at a time: a tanker for fuel, a tipper for grain, a flatbed for planks. Feeding a town that wants four things means four lines, or one truck that waits around. These trucks just load what's waiting — up to four kinds at once — and drop each one where it's wanted.

Why is Load Manager included?

Here's a little secret about these trucks. 😄

I originally wanted an easier way to manage cargo loading on trains and other vehicles. Then I had a thought: why can't trucks carry a proper mix of cargo too?

So we built the mixed-cargo trucks!

The funny thing is, Load Manager was the idea that inspired them in the first place. The trucks made it out into the world first, but the loader was always the reason behind them.

So it only seems fair to package them together. Now you can experience the trucks the way I originally imagined them.

Four cargo types. One truck. Precise loading at every stop.

And if you prefer the original loading controls, you can switch Load Manager off in the mod settings.

Enjoy!

The trucks

  • PYT Mixed Cargo Tilt (1975–1995) — a 1970s European flat-front tractor and a canvas tilt trailer.
  • PYT Mixed Cargo Box Van (1990–2015) — a 1990s European aero tractor with a roof light bar, and a box van with a roll-up door.
  • PYT Mixed Cargo Mega Curtain-Sider (from 2010) — a modern European high-roof tractor and a low-deck mega trailer with a lift axle.
  • PYT Mixed Cargo Aero Box (from 2025) — an electric long-nose tractor, quiet and clean, with screens in the cab, and a boat-tailed aero box.

How it works

  • Four slots per truck. Each slot takes bulk, liquid, goods or flatbed cargo — the truck's window shows all four specializations.
  • Set the mix on each stop's Load panel — the game's own panel. Pick the cargos, give each a share, and the truck fills its slots to match.
  • Working indicators and night lights.
  • Worth buying as a plain truck too: fair, vanilla-style speed, power and capacity for its era. The mixed load is the bonus.

Latest update

1.3 — SMARTER LOADS, LIGHTER FILES

Four trailers, four cargo types, and now a planner that knows which goes where. It came with its own pen.

In plain terms: the PYT - Load Manager is built into this pack, the download is about 24 MB lighter, and the trucks are cheaper to draw from far away.

  • New: the Load Manager is built in — a Loads card in every freight line's window with a slider for each stop, a Load Manager button in a vehicle's window, and an overview page behind the PYT button. Set each stop to load one cargo, a mix, or nothing at all; Smart fill leaves one-cargo stops alone. No other mod is needed
  • New: you can switch it off. Don't want it? Open the mod manager, pick this mod and set PYT: Load Manager to Off before you load the game. Nothing of the Load Manager shows and nothing of it runs; the vehicles, their loading and their look are untouched. It is On by default
  • Plays well with others: the Load Manager is the tool inside the standalone mod PYT - Load Planner, and this pack carries its own copy of it. If you install PYT - Load Planner too, it runs the Load Manager and this copy stays quiet. With several PYT mixed-cargo mods, only one copy runs, so nothing ever shows twice
  • Lighter: the shop pictures are compressed without losing a pixel (about 24 MB off the download), and the trucks' far-away models are simpler — about three quarters fewer triangles from 400 m — which helps big fleets
